# 냉각팬 제어 모델 검증 결과 보고서

버전: v0.1 | 실행일: 2026-10-20 (Asia/Seoul)

## 환경과 근거

MATLAB R2023a Update 8과 설치된 Simulink에서 실제 시뮬레이션했다. Python 3.11 표준 라이브러리로 결과를 판정했다. 상세 제품 버전·UTC 실행 시각은 [실행 환경](../results/actual/environment.json), 실행 파일·데이터 식별은 [SHA-256 기록](../results/reproducibility.json)에 남겼다. 해당 파일을 포함한 Git 커밋으로 저장소 버전을 확인한다.

## 정상 모델

| 항목 | 결과 | 근거 |
|---|---|---|
| 요구사항 기반 동적 테스트 | 23/23 PASS | [요약](../results/actual/summary.csv) |
| 모델 설정 자동 검사 | 15/15 통과 | [설정 검사](../results/model-configuration-checks.csv) |
| Python 판정 도구 검사 | 5/5 통과 | tests/test_result_checker.py |
| 모델 구조 커버리지 | 미측정 | 커버리지 도구 사용하지 않음 |

시간 테스트는 계단 입력과 10ms 관찰 간격으로 실행했다. 50ms 입력 변화에서 기존 출력을 유지하고 다음 100ms 평가에 반영하는지 확인했다. 10ms 미만의 변화는 직접 관찰 범위 밖이다.

## 초기화 및 설계 리뷰

| 검토 항목 | 결론 |
|---|---|
| STATIC-INIT: 초기 팬 상태 | Unit Delay의 InitialCondition=false를 설정 검사로 확인 |
| STATIC-INIT: 초기 고장 표시 | 별도 상태를 갖지 않고 t=0부터 센서 입력으로 계산함을 설계·연결에서 확인. 첫 평가 전 OFF는 독립 출력 샘플로 관찰하지 않음 |
| 오류 우선순위 | SensorOverride가 정상 온도 판단 뒤에 위치하며 오류 시 ON을 선택 |
| 최종 명령 피드백 | SensorOverride 출력이 PreviousFan 입력으로 연결됨을 자동 설정 검사로 확인 |
| 입력 샘플링 | 온도·센서 입력 모두 100ms로 샘플링되며 고장 표시도 샘플링된 센서로 계산 |

설정 검사 통과는 동작 전체에 대한 정적 분석이나 증명이 아니다. REQ-001은 위 정적 근거로 검토했고, 동적 테스트는 첫 평가 이후 출력에 대해 수행했다.

## 결함 주입 결과

| 의도적 결함 | 변경 내용 | 검출 테스트 | 실패 테스트 수 |
|---|---|---|---|
| on_strict | ≥95℃를 >95℃로 변경 | TC-003 등 | 8/23 |
| wrong_feedback | 최종 출력 대신 오류 처리 전 명령 저장 | TC-017 | 1/23 |
| no_override | 오류 시 강제 ON 대신 정상 온도 명령 사용 | TC-012 등 | 8/23 |

세 결함 모두 지정한 테스트에서 실제 팬 출력 불일치로 검출했다. 미실행이나 파일 누락을 결함 검출로 간주하지 않았다. 상세 결과는 [결함 요약](../results/mutation-summary.md)과 results/mutations/에 기록했다.

결함 버전은 메모리에서만 실행하고 파일에 저장하지 않았다. 각 테스트는 독립 초기화하며 실행 종료 시 변경 모델을 저장하지 않고 닫는다. 최종 .slx는 정상 모델이다.

## 남은 범위

- 비교·상태·오류 우선순위의 세 결함에 대한 검출 결과이며 모든 가능한 결함을 검출한다는 의미는 아니다.
- 입력 계약을 위반하는 센서 정상+NaN/Inf 조합은 검증 대상에서 제외했다.
- 평가 사이의 짧은 오류를 기억하는 기능, 실제 냉각 성능, ECU·하드웨어 검증은 범위 밖이다.
- MISRA 검사, ISO 26262 인증, 형식 검증, C 코드 비교는 수행하지 않았다.
- 문서 변경 시 영향받는 모델·테스트·추적성 표를 함께 검토해야 한다.

실행 방법은 [README](../README.md)를 따른다.
