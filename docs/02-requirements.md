# 냉각팬 제어 소프트웨어 요구사항 정의서

버전: v0.1 | 합의일: 2026-10-20

## 목적과 범위

온도와 센서 정상 여부에 따라 팬 명령과 고장 표시를 결정한다. 실제 팬 회전, 냉각 성능, 센서 하드웨어 및 ECU는 범위 밖이다. 임계값과 주기는 학습용 가정이다.

## 인터페이스

| 구분 | 신호 | 의미 | 자료형·단위 |
|---|---|---|---|
| 입력 | temperature | 측정 온도 | double, ℃ |
| 입력 | sensor_valid | 정상 true / 오류 false | Boolean |
| 출력 | fan_cmd | ON true / OFF false | Boolean |
| 출력 | fault_flag | 고장 true / 정상 false | Boolean |

## 외부 인터페이스 가정

| ID | 가정 |
|---|---|
| ASM-001 | 외부 시스템이 온도의 유효성을 판단하여 sensor_valid로 전달한다. |
| ASM-002 | sensor_valid=true이면 temperature는 유효한 유한 실수이다. |
| ASM-003 | 내부 온도 유효성 판단은 하지 않는다. sensor_valid=false이면 온도를 제어 판단에 사용하지 않는다. |

## 동작 요구사항

| ID | 요구사항 |
|---|---|
| REQ-001 | 초기화 시 fan_cmd와 fault_flag를 false로 설정한다. |
| REQ-002 | 초기화 후 t=0에서 첫 입력을 평가하고 출력을 갱신한다. |
| REQ-003 | 이후 100ms 주기로 입력을 평가하고 출력을 갱신한다. |
| REQ-004 | 평가 시점 사이에는 직전 평가에서 결정한 출력을 유지한다. |
| REQ-005 | 평가 시 센서가 정상이고 온도 ≥95℃이면 fan_cmd=true로 설정한다. |
| REQ-006 | 평가 시 센서가 정상이고 온도 ≤90℃이면 fan_cmd=false로 설정한다. |
| REQ-007 | 평가 시 센서가 정상이고 90℃<온도<95℃이면 직전 팬 명령을 유지한다. 첫 평가에서는 초기 팬 명령을 사용한다. |
| REQ-008 | 평가 시 센서 오류이면 온도보다 우선하여 fan_cmd=true로 설정한다. |
| REQ-009 | 평가 시 센서 오류이면 fault_flag=true로 설정한다. |
| REQ-010 | 평가 시 센서 정상이면 fault_flag=false로 설정한다. |
| REQ-011 | 센서 복구를 확인한 평가 시점부터 REQ-005~007을 적용한다. |

REQ-001의 초기화 전후 상태와 t=0 평가 후 출력은 구분한다. 초기값을 100ms 동안 유지하는 요구사항은 아니다. 고장 표시에는 이력이 없으며 각 평가의 센서 정상 여부로 결정한다.

## 동작 판단표

| 센서 | 온도 | 이전 팬 | 팬 명령 | 고장 표시 |
|---|---|---|---|---|
| 오류 | 무관 | 무관 | ON | ON |
| 정상 | ≥95℃ | 무관 | ON | OFF |
| 정상 | ≤90℃ | 무관 | OFF | OFF |
| 정상 | 90℃ 초과 95℃ 미만 | OFF | OFF | OFF |
| 정상 | 90℃ 초과 95℃ 미만 | ON | ON | OFF |

평가 시점 사이에 발생했다가 사라지는 짧은 오류를 기억하는 기능은 포함하지 않는다.
