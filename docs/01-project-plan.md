# Simulink 기반 차량 냉각팬 제어 모델 검증 및 테스트 자동화 프로젝트 계획서

문서 버전: v0.1  
상태: 초안  
작성일: 2026-10-20

## 1. 목적

MATLAB/Simulink를 활용하여 차량 냉각팬 제어 모델을 구현하고, 요구사항 기반의 정적 점검과 동적 검증을 수행한다. 온도 경계값, 상태 전이, 센서 오류 상황에 대한 테스트를 설계하여 모델의 결함을 발견하고 수정하는 과정을 경험한다.

또한 Python으로 테스트 데이터 생성과 결과 판정, 보고서 작성을 자동화하여 반복 가능한 검증 환경을 구축한다.

## 2. 배경

차량 냉각팬 제어 소프트웨어는 온도에 따라 팬을 작동시키고, 임계값 부근에서 불필요한 작동과 정지가 반복되지 않도록 제어해야 한다. 센서 오류가 발생했을 때의 동작도 명확하게 정의되어야 한다.

이러한 제어 로직은 정상적인 입력에서 동작하더라도 온도 경계값, 초기 상태, 오류 발생 및 복구 조건에서 결함이 나타날 수 있다. 따라서 단순한 기능 구현을 넘어, 요구사항을 구체화하고 다양한 조건에서 동작을 검증하는 과정이 필요하다.

본 프로젝트에서는 냉각팬 제어를 학습용 사례로 선정하여 모델 기반 개발과 검증 절차를 적용한다.

## 3. 해결방안

### 3.1 요구사항 정의 및 검증 기준 수립

온도에 따른 팬 ON/OFF, 이전 상태 유지, 센서 오류 대응 및 복구 동작을 요구사항으로 정의한다. 입력·출력 신호, 초기 상태, 제어 주기를 명시하고 각 요구사항에 고유 ID를 부여한다.

온도 임계값, 제어 주기, 오류 및 복구 조건은 학습용 가정으로 설정하고 요구사항 정의서에서 확정한다.

### 3.2 Simulink 제어 모델 구현 및 정적 점검

요구사항을 바탕으로 냉각팬 제어 모델을 구현한다. 서로 다른 ON/OFF 임계값을 사용하는 히스테리시스를 적용하고, 센서 오류 처리 로직을 구성한다. 모델의 자료형, 샘플 시간, 초기값, 블록 연결 등을 실행 전에 점검하고 결과를 기록한다.

정적 점검 기록에는 수동 리뷰와 도구 자동 검사의 수행 여부 및 적용 범위를 구분하여 명시한다.

### 3.3 요구사항 기반 동적 검증

정상 동작, 온도 경계값, 상태 전이, 센서 오류 및 복구 시나리오를 설계한다. 시뮬레이션의 실제 출력과 사전에 정의한 기대 결과를 비교하여 적합성을 판정한다.

의도적으로 결함을 삽입한 모델에도 테스트를 수행하여 테스트의 결함 검출 여부를 확인한다. 기대 결과는 요구사항으로부터 도출하고, 결함 주입 버전과 정상 버전을 구분하여 기록한다.

### 3.4 Python 기반 테스트 자동화 및 결과 관리

Python으로 테스트 입력 데이터 생성, 시뮬레이션 결과 판정, 그래프 및 보고서 작성을 자동화한다. 요구사항과 테스트 결과를 연결하고, 결함 수정 후 기존 테스트를 재실행하여 수정에 따른 영향을 확인한다.

결과에는 모델 및 테스트 데이터 버전과 실행 환경을 기록한다. 요구사항 테스트 수행률과 모델 구조 커버리지는 구분하며, 커버리지 도구가 없는 경우 측정하지 않은 수치를 제시하지 않는다.

### 3.5 GitHub 기반 산출물 및 변경 이력 관리

프로젝트 문서, Simulink 모델, MATLAB·Python 코드, 테스트 데이터 및 검증 결과를 하나의 GitHub 저장소에서 관리한다. 요구사항 ID와 테스트 ID를 연결하고, 결함 및 개선 사항은 GitHub Issues로 기록하여 변경 이유와 검증 결과를 추적할 수 있도록 한다.

문서는 Markdown으로 작성하며, Simulink 모델 변경 시 설계 설명과 변경 이유를 함께 갱신한다.

### 3.6 수행 범위 및 완료 기준

검증 범위는 제어 모델의 출력 명령으로 한정하며, 실제 차량의 냉각 성능과 하드웨어 동작, 실제 ECU 탑재는 포함하지 않는다. C 코드 구현 및 모델과의 결과 비교는 기본 범위 완료 후 확장 항목으로 검토한다.

기본 범위의 완료 기준은 다음과 같다.

- 정의한 모든 요구사항에 테스트를 연결한다.
- 계획한 테스트를 실행하고 실패 원인을 분석하여 조치 또는 미해결 사유를 기록한다.
- 결함 주입 및 수정 전후 비교 결과를 남긴다.
- 자동화 실행 절차, 환경 및 검증 결과를 문서화한다.

## 4. 기대효과

- **모델링 역량 확보:** MATLAB/Simulink를 활용하여 상태를 갖는 제어 로직을 구현하고 동작을 이해한다.
- **검증 역량 확보:** 요구사항에서 테스트를 도출하고, 경계값·상태 전이·오류 상황의 결함을 분석하는 경험을 쌓는다.
- **자동화 역량 확보:** Python을 활용하여 반복 검증의 수작업을 줄이고, 일관된 기준으로 결과를 판정한다.
- **검증 근거 확보:** 요구사항, 모델, 테스트, 결함 수정 이력을 연결하여 재현 가능한 포트폴리오를 완성한다.
