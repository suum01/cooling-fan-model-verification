# CoolingFan-Controller

## Simulink 기반 차량 냉각팬 제어 모델 검증 및 테스트 자동화

온도와 센서 상태에 따라 팬 구동 명령을 결정하는 제어 모델을 구현하고, 요구사항 기반 검증과 Python 테스트 자동화를 수행하는 학습 프로젝트입니다.

현재 단계는 프로젝트 계획 수립입니다. Simulink 모델, 실행 코드 및 검증 결과는 아직 작성되지 않았습니다.

## 프로젝트 목표

- MATLAB/Simulink를 활용한 냉각팬 제어 모델 구현
- 모델의 자료형, 샘플 시간, 초기값 및 연결에 대한 정적 점검
- 경계값, 상태 전이, 센서 오류 및 복구에 대한 동적 검증
- Python 기반 테스트 데이터 생성, 결과 판정 및 보고서 작성 자동화
- 요구사항·모델·테스트·결과 간 추적성 확보

## 문서

## 계획된 구성

| 경로 | 용도 |
|---|---|
| `docs/` | 계획서, 요구사항, 설계 및 검증 문서 |
| `models/` | Simulink 모델 |
| `scripts/matlab/` | 모델 실행 및 출력 저장 |
| `scripts/python/` | 테스트 데이터 생성 및 결과 판정 |
| `tests/inputs/` | 테스트 입력 |
| `tests/expected/` | 요구사항에서 도출한 기대 결과 |
| `results/` | 검증 요약 결과 및 그래프 |

폴더와 파일은 실제 산출물이 생길 때 추가합니다.

## 개발 환경 및 실행 방법

MATLAB/Simulink 버전, 사용 가능한 추가 제품, Python 버전은 환경 확인 후 기록합니다. 실행 방법과 Python 의존 패키지는 코드 구현 시 추가합니다.

## 관리 원칙

- 문서는 Markdown으로 작성하고 요구사항과 테스트에 고유 ID를 부여합니다.
- 모델 변경 시 관련 요구사항과 변경 이유를 커밋 또는 문서에 기록합니다.
- 결함은 GitHub Issues에 재현 조건, 원인, 수정 및 재검증 결과를 기록합니다.
- 결과에는 모델·테스트 데이터 버전과 실행 환경을 남깁니다.
- 재현에 필요한 요약 결과와 대표 그래프를 저장하고 임시 생성물은 제외합니다.

## 범위

학습용으로 가정한 제어 요구사항에 따라 출력 명령을 검증합니다. 실제 차량의 냉각 성능, 하드웨어 동작 및 ECU 탑재는 범위에 포함하지 않습니다.
